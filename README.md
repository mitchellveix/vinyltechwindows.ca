# VinylTech Windows & Doors Website

A modern, custom WordPress Full Site Editing (FSE) theme built for **VinylTech Windows & Doors**. This project replaces the company's legacy static website with a fast, responsive, and easy-to-manage WordPress website using the Block Editor.

---

## Features

* 🎨 Custom WordPress Block Theme
* 🧱 Full Site Editing (FSE)
* 📱 Fully responsive layouts
* 🖼️ Custom editable hero patterns
* 🪟 Dynamic Window & Door product pages
* ⚙️ Advanced Custom Fields (ACF) integration
* 🎯 SEO-friendly structure
* ♿ Accessibility-focused development
* 🚀 Performance optimized
* 🎨 Custom CSS architecture

## Development

### Clone the repository

```bash
git clone https://github.com/mitchellveix/vinyltechwindows.ca.git
```

### Local Development

This project is designed to run in a local WordPress development environment such as:

* LocalWP
* Studio by WordPress.com
* DevKinsta
* Docker

Copy the theme into:

```
wp-content/themes/vinyltech
```

Then activate the theme from the WordPress admin.
